# BeachDevs

This organization previously hosted the BeachDevs projects. All repositories have
been consolidated under the **digplan** account.

**All code now lives at [https://github.com/digplan](https://github.com/digplan).**

Old `beachdevs/<repo>` URLs automatically redirect to the corresponding
`digplan/<repo>`. If you have a stale local clone, update your remote:

```bash
git remote set-url origin https://github.com/digplan/<repo>.git
```

For questions, please [open an issue on the relevant repo](https://github.com/digplan) under digplan.
